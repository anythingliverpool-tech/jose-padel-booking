# José Padel Booking

Mobile-first prototype for presenting a simpler alternative to managing padel lesson availability in WhatsApp.

## Prototype features
- Public list of available lesson slots grouped by day
- Four spaces per lesson with live availability
- Name + mobile booking flow
- In-person payment only
- Pricing explanation based on attendance
- José Admin view
- Add different lesson times on any date
- Add several times in one action
- Venue and court selection
- View and remove player bookings
- Delete lesson slots

## Run
`npm install && npm start`

This is a presentation prototype. The current server stores data in memory, so a production version should use a persistent database and protected admin authentication.
